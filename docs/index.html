A) Overview - top

Mosaic Product Layouts for Elementor is a WordPress plugin that adds three WooCommerce-focused Elementor widgets under the Mosaic Product Layouts category:

  • Products Layout for displaying WooCommerce products in creative grid-based cards.
  • Categories Layout for displaying product categories in custom grid-based cards.
  • Single Product Layout for displaying one chosen product with movable elements such as image, title, price, excerpt, rating, and add to cart.

The widgets are designed for users who want more visual control than a standard grid. You can choose a preset layout, drag and resize items in the editor, save your own setups, and apply style presets to accelerate design work.

Main strengths

  • Drag-and-resize layout editing directly inside Elementor.
  • Separate layout control for desktop, tablet, and mobile editing.
  • Style presets for fast starting points.
  • Saved setups for reusing complete layout and style combinations.
  • WooCommerce data integration for products and categories.

B) Requirements - top

Before installing the plugin, make sure your site meets these requirements:

  • WordPress 6.0 or newer.
  • PHP 7.0 or newer.
  • Elementor installed and activated.
  • WooCommerce installed and activated.

Elementor Pro is not required for the widget functionality documented here.

Important: The widgets rely on WooCommerce data. If WooCommerce is not active, product and category content cannot load correctly.

D) Installation - top

You can install the plugin using the WordPress admin dashboard or with FTP/SFTP.

Install through WordPress admin

  1. Log in to your WordPress admin area.
  2. Go to Plugins > Add New > Upload Plugin.
  3. Upload the plugin ZIP file.
  4. Click Install Now.
  5. After installation completes, click Activate Plugin.

Install through FTP/SFTP

  1. Extract the plugin ZIP on your computer.
  2. Upload the mosaic-product-layouts-for-elementor folder to /wp-content/plugins/.
  3. Go to Plugins in WordPress admin.
  4. Activate Mosaic Product Layouts for Elementor.

After activation

  1. Confirm that Elementor and WooCommerce are active.
  2. Edit a page with Elementor.
  3. Search for the widget category Mosaic Product Layouts.
  4. Drag one of the plugin widgets into your page.

E) Getting Started - top

The fastest way to start is:

  1. Open a page in Elementor.
  2. Add one of the Mosaic Product Layouts widgets.
  3. Pick a predefined layout first.
  4. Adjust the widget query or product source.
  5. Customize spacing, alignment, visibility, and styles.
  6. Drag and resize items in the preview area if you want a custom layout.
  7. Click Update or Publish to save the current page state.

Important: Layout changes made by dragging or resizing are saved with the page only after you click Update or Publish in Elementor.

All three widgets follow the same general control pattern:

  • Content tab for choosing data, product, or saved setups.
  • Layout tab for grid behavior, layout presets, custom layout storage, and helper tools.
  • Style tab for typography, image display, alignment, color, borders, and presets.

F) Products Layout Widget - top

The Products Layout widget displays WooCommerce products in a creative product card grid.

Main content options

  • Order By: date, title, price, popularity, or rating.
  • Order: ascending or descending.
  • Categories: limit the query to selected product categories.
  • On Sale Only: show only sale products.
  • Featured Only: show only featured products.
  • Enable Pagination: split products across multiple pages.

Layout options

  • Predefined Layouts: start from a ready-made card arrangement.
  • Custom Layout: automatically stores your drag-and-resize changes.
  • Reset Layout: return to the selected predefined layout.
  • Add Item: add an additional grid slot to the layout.
  • Grid Gap and Grid Row Height: control grid spacing and row density.
  • Allow Overlap and Compaction Type: define how items behave when moved.
  • Grid Visualization: display the underlying grid as a placement aid.

Styling options

  • Text tab for title, price, button, and taxonomy text sizes.
  • Layout tab for product card orientation and internal alignment.
  • Image tab for image size, fit, and focal point positioning.
  • Colors tab for text, links, and backgrounds.
  • Borders tab for borders, radius, and shadow.
  • Badges and other controls for sale badge styling and rating sizing.

Element visibility and order

You can reorder and show or hide product card elements such as Title, Price, Rating, Add to Cart, Categories, and Brands using the Element Order & Visibility section.

Typical workflow

  1. Add the widget to the page.
  2. Choose the products you want to display using the query controls.
  3. Select a predefined layout.
  4. Adjust card styling or apply a style preset.
  5. Optionally drag and resize grid items for a custom layout.
  6. Save the result as a setup if you want to reuse it later.

G) Categories Layout Widget - top

The Categories Layout widget displays WooCommerce product categories in a custom card grid.

Main content options

  • Categories Per Page: control how many categories are displayed.
  • Order By: name, ID, slug, or product count.
  • Order: ascending or descending.
  • Hide Empty Categories: exclude categories with no products.
  • Parent Category: limit output to subcategories of a selected parent.
  • Include Categories: directly choose which categories to show.

Layout options

The Categories widget uses the same layout controls as the Products widget: predefined layouts, reset, add item, grid gap, row height, overlap control, compaction behavior, helper grid, and custom drag-and-resize editing.

Content elements

You can reorder and toggle the visibility of category Title, Count, and Description.

Styling options

  • Style presets for rapid card styling.
  • Text controls for title, product count, and description.
  • Layout controls for card alignment and spacing.
  • Image controls for category images.
  • Color and border controls for the card appearance.

Typical workflow

  1. Add the widget to the page.
  2. Choose whether to show all categories, a parent branch, or a hand-picked set.
  3. Select a predefined layout and adjust the grid.
  4. Reorder visible elements if necessary.
  5. Apply a style preset or customize card styling manually.
  6. Save or publish the page.

H) Single Product Layout Widget - top

The Single Product Layout widget is built for displaying one WooCommerce product with individually placed elements in a draggable grid.

Main content options

  • Product: choose the WooCommerce product to display. The custom selector supports search.
  • Saved Setups: save, load, or delete reusable layout and style combinations.

Layout options

  • Predefined layouts: choose an element arrangement as a starting point.
  • Reset layout: return to the predefined arrangement.
  • Grid gap and Grid row height: control spacing and vertical rhythm.
  • Allow overlap and Compaction type: control how elements interact when moved.
  • Grid visualization: show the helper grid.
  • Element outlines and labels: display element boundaries to make editing easier.

Styling options

  • Style presets for quick full-widget styling.
  • Global element styles to set defaults for all elements.
  • Per-element style sections for detailed control of individual parts of the product output.

What can be styled

Depending on the selected element, controls may include text size, text color, background, horizontal alignment, vertical alignment, padding, border, border radius, and box shadow.

Typical workflow

  1. Add the widget to the page.
  2. Select the product using the search field.
  3. Choose a predefined layout.
  4. Use outlines and helper grid while dragging elements into position.
  5. Apply a style preset or refine the global and per-element styles.
  6. Save the page and optionally save the result as a reusable setup.

I) Layout Editing, Helpers, and Responsive Workflow - top

All widgets support a layout-editing workflow inside Elementor.

How editing works

  1. Start with a predefined layout.
  2. Drag grid items in the preview to move them.
  3. Resize grid items where resizing is available.
  4. Use helper grid overlays for more precise positioning.
  5. Use Elementor's device mode switcher to review desktop, tablet, and mobile views.
  6. Click Update or Publish when you are done.

Resetting your work

If a custom layout becomes too complex, use the widget's Reset Layout button to discard layout edits and return to the selected predefined layout.

Responsive editing tip

Always check tablet and mobile views after finishing a desktop design. Some spacing, alignment, or text size controls are responsive and can be adjusted per device.

Important: If you drag or resize items but leave the page without clicking Update or Publish, those layout changes will not be saved.

J) Saved Setups and Style Presets - top

The plugin provides two ways to accelerate design work: Saved Setups and Style Presets.

Saved Setups

  • Saved Setups store a combination of layout and style settings.
  • You can save the current widget configuration, load a previous setup, or delete one you no longer need.
  • Use Saved Setups when you want to reuse a full widget configuration on the same site.

Style Presets

  • Style Presets apply a prepared visual design package quickly.
  • Use a preset as a starting point, then refine spacing, colors, borders, or typography manually.
  • Use Style Presets when you want to speed up styling but keep your own layout structure.

Recommended order of work

  1. Choose the widget and content source.
  2. Choose or build the layout.
  3. Apply a style preset.
  4. Fine-tune individual settings.
  5. Save the final result as a Saved Setup for reuse.

K) Troubleshooting - top

The widget does not appear in Elementor.

  • Confirm that the plugin is activated.
  • Confirm that Elementor is installed and active.
  • Search for the widget under the Mosaic Product Layouts category.

The widget appears but shows no product or category data.

  • Confirm that WooCommerce is active.
  • Confirm that your store has published products or categories.
  • Check the widget query settings, selected categories, or selected product.

My layout changes are lost after leaving the page.

  • Make sure you clicked Update or Publish after dragging or resizing items.
  • Use the helper grid and reset tools to rebuild the layout if needed.

Styling looks different on mobile.

  • Open Elementor's responsive mode and review tablet/mobile controls.
  • Check responsive typography, padding, and alignment settings.

Product search in Single Product Layout does not find the expected item.

  • Confirm the product is published.
  • Try typing at least part of the product name.
  • Make sure WooCommerce products exist and are visible to queries.
