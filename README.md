Creative WooCommerce product, category, and single-product layouts for Elementor with responsive grid editing and style presets.

== Description ==

Mosiac Product Layouts for Elementor adds custom Elementor widgets for WooCommerce:

* Content Layout
* Categories Layout
* Single Product Layout

Key capabilities:

* Responsive grid editing for desktop, tablet, and mobile layouts
* Per-element visibility and ordering controls
* Style presets for fast visual setup
* Editor-friendly React-powered rendering and interactions

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate the plugin from the WordPress Plugins screen.
3. Ensure Elementor and WooCommerce are installed and active.
4. Edit a page with Elementor and use the widgets under the Micemade category.

== Development ==

Use these commands during development:

* `npm install`
* `npm run watch`
* `npm run build`

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

Yes. The widgets are designed for WooCommerce product and taxonomy data.

= Does this plugin require Elementor Pro? =

No. It works with Elementor, though your site setup may include Elementor Pro.
