Mosaic Contents for Elementor

Mosaic Contents for Elementor is a layout design plugin for Elementor that helps you build free-form, grid-based content sections without being boxed in by rigid default layouts. Instead of fighting flexbox, CSS grid, or column structures, you place and size items freely on an underlying snap grid that keeps everything aligned. It is made for bloggers, content creators, freelancers, agencies, and developers who want more visual control over how posts and page sections are composed inside Elementor.

This Elementor plugin includes two dedicated widgets: Content Layout and Widgets Layout. Both share the same free-form grid engine, with draggable, resizable composition and responsive editing for desktop, tablet, and mobile — so you decide exactly where each item sits at every breakpoint.

Main Features

  • Content Layout widget for posts, pages, and custom post types arranged as cards in a free-form grid
  • Widgets Layout widget that drops any Elementor widget into free-form grid cells
  • Free-form drag-and-resize positioning on an underlying snap grid — no flexbox, CSS grid, or column constraints
  • Responsive grid layout editing for desktop, tablet, and mobile breakpoints
  • Overlap and z-index controls for layered, magazine-style compositions
  • Post query controls: post type, taxonomy and terms, order, sticky posts, pagination, and custom post meta
  • Custom element visibility and ordering controls for content blocks
  • Style presets for fast design setup and consistent presentation
  • Saved setups to store, reload, and reuse complete widget configurations
  • Per-cell styling for the Widgets Layout: background, padding, alignment, text and link colors, overlay color, border, radius, and shadow
  • Multiple native widgets per cell, with nested Containers and drag-between-cells editing
  • Image focal point controls for precise visual composition
  • WordPress REST API content loading and an editor-friendly live preview workflow

Included Elementor Widgets

Content Layout

Query posts or any custom post type and lay them out as cards in a free-form grid. Filter by taxonomy and terms, control order, sticky posts, and pagination, and add custom post-meta fields to each card. Style titles, excerpts, images (with focal point), colors, and borders, reorder or hide individual card elements, and apply style presets. Ideal for blog and news grids, magazine layouts, portfolio and case-study sections, and editorial homepages.

Widgets Layout

Turn each grid cell into a drop zone for any Elementor widget — headings, images, buttons, icons, Containers, and more. Dropped widgets stay real, native, editable Elementor elements, so you edit them in the panel and they save with the page as usual. Stack multiple widgets per cell, nest Containers/Grid/Flexbox with inner widgets, drag widgets between cells, and style every cell individually. Ideal for free-form hero sections, feature blocks, custom landing pages, and creative page compositions that go beyond standard rows and columns.

Why This Plugin Stands Out

Most Elementor layout tools still rely on rows, columns, and flex containers, which limits how freely you can arrange content. Mosaic Contents for Elementor focuses on free-form layout control. The underlying grid gives you snapping and structure while letting items move, resize, overlap, and layer exactly where you want them. That makes it a strong choice for magazine and editorial designs, portfolios, creative landing pages, and any WordPress site that needs more expressive layouts than a standard grid.

It also speeds up your design workflow with reusable saved setups, ready-to-apply style presets, and per-cell styling. Build a polished layout once, then reuse that visual system across multiple sections or client projects with less repetitive setup work.

Compatibility

Mosaic Contents for Elementor is built for WordPress and Elementor. Elementor Pro is not required. WooCommerce is not required either — the Content Layout widget works with any public post type, so it can display WooCommerce products if that post type is selected. It suits content creators, designers, and developers who want more engaging, free-form layouts while staying inside a familiar Elementor workflow.
